# Restaurant Roulette

## Project Overview

Restaurant Roulette is a full-stack web application designed
to help users decide where to eat using an interactive
spinning wheel.

Users can manage their own restaurant list, randomly select
a restaurant, track visited restaurants, and manually restore
restaurants to the wheel.

Restaurant data is stored in a MySQL database, allowing
information to persist between sessions.

## Project Motivation

I created this personal portfolio project to strengthen
my full-stack development skills and build a practical
application that solves an everyday problem.

## Planned Features

- Add restaurants
- Edit restaurants
- Delete restaurants
- Interactive spinning wheel
- Random restaurant selection
- Restaurants Visited section
- Exclude visited restaurants from future spins
- Manually restore restaurants to the wheel
- Persistent database storage
- Responsive user interface
